# Examples

This directory contains sanitized, documentation-oriented examples that illustrate the shape of core Proof-of-Care artifacts without exposing the private implementation.

Included examples:

- `sample-manifest-shape.md`: bounded authority surface for a supervised session
- `sample-decision-log.md`: single governed action outcome with audit context
- `sample-policy-replay.md`: historical decision replay against a proposed policy delta

These examples are intentionally partial. Their purpose is to make the architecture easier to evaluate, not to recreate the full system.
